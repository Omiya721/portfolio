# 【自主制作】Webクリエイター ポートフォリオサイト

私自身のスキル、制作実績、および仕事への取り組み姿勢を伝えるためのポートフォリオサイトです。
実務で求められる「正確なコーディング」「WordPressの高度なカスタマイズ」を証明できるよう設計・実装しました。

## 🌐 制作概要
* **制作期間**: 2週間
* **仕様**: レスポンシブ対応（PC / スマホ）、WordPressテーマ化
* **目的**: 自身のコーディングスキルと実務対応力を一目で判断していただくため作成。

## ✨ 実装・設計のこだわり（アピールポイント）

### 1. メンテナビリティを意識したSass設計（BEM手法）
Sass（SCSS）を使用し、BEMの手法を取り入れた設計を行っています。
クラス名の重複を防ぎ、将来的な修正や拡張が容易な、見やすく、編集しやすいコード設計を意識しました。

### 2. モダンプラットフォームへの適応（scroll-behavior）
ページ内のスムーズスクロールの実装にあたり、CSSの `scroll-behavior: smooth;` を採用しました。
サイトの軽量化と、ブラウザの標準機能に準拠した実装を意識しています。

### 3. 実務を想定したセキュリティとフォーム設計
ただサイトを作るだけでなく、セキュリティを考慮したBasic認証の設定や、実稼働するお問い合わせフォームの設置などの構築を行っています。

## 💡 生成AIツールの活用について
本サイトの開発においては、効率化とコード品質の向上のため、Google Gemini等の生成AIを「開発パートナー」として活用しています。
単なるコードの自動生成に頼るのではなく、全体のディレクトリ構成やSassのコンポーネント設計を自身で定義した上で、デバッグやリファクタリング、より適切な記述の提案をAIに指示し、実務に必要な「スピード」と「品質」を両立した開発プロセスを導入しています。
